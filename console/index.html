Encryptoglyph

Encryption at rest

Seal the field. Keep the key.

Encryptoglyph wraps each value in an XChaCha20-Poly1305 envelope, derives the data key with HKDF, and leaves plaintext out of the assistant.

Field sealing

Record context is authenticated with the ciphertext, so a blob cannot move to another row.

Key fingerprints

The console shows a fingerprint. The key bytes stay in process memory and are wiped on shred.

Vaults that already seal passwords

Komboe adopts this envelope for vault items.

Encrypted file backup

Inventory here is a sealed manifest. For whole-file backup, restic is the usual tool, and age seals files.

Drop into a GoDesk app

A few lines adopt the same sidecar in GitGoat, RailYard, Portkyl, and Cerebro.

Seal a field

The value is sent only to the seal endpoint. The assistant never receives it.

Blind index

Returns a truncated HMAC. The value is not stored and is not repeated in the result.

Keys

New keys are random. This page lists fingerprints only.

Shred a retired key

Type the fingerprint of a key that is not current. The current key stays until you rotate.

Custody

This console holds session keys in process memory. It does not pretend a custody service is connected.

Agent

Commands run without a model. When Ollama is configured, it may only choose an action. It never sees values or keys.

Adopt

Same library in-process, or the versioned HTTP sidecar. See INTEGRATION.md.
