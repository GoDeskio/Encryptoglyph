# Encryptoglyph

Encryptoglyph is one console for encryption at rest, key custody, and encrypted backup. It is built for MSPs (GoDesk first), self-hostable on Proxmox or hosted by GoDesk, and it produces insurer- and auditor-ready evidence.

This repository is the M0 scaffold: a compose skeleton, a health-only API, and CI. The product plan, architecture, and milestones are in [docs/plan.md](docs/plan.md).
